# 阿拉伯语童书工作台

本地编辑、插画和人工审核工作台。首次启动内置《خُبْزَتَانِ، مِنْ فَضْلِكَ》八页阿语样稿。

## 本地启动

需要 Python 3.10 或更高版本。无需安装第三方依赖。

```bash
python3 app.py
```

浏览器打开 http://127.0.0.1:8765。书稿的 SQLite 数据库、修订快照和上传素材位于 `data/`，请备份这个目录。可通过 `ARCHILDBOOK_DATA` 和 `ARCHILDBOOK_PORT` 修改存储位置和端口。

## 制作样书

1. 在「角色参考」上传有权使用的原创角色图。
2. 在「分镜」调整逐页阿语正文、插画场景和出场角色。由母语审稿人批准正文。
3. 上传 PNG/JPEG 候选，或启用下方 OpenAI 接口。选用插画后让审读者批准图文与文化。
4. 在「书籍与导出」填写作者署名。上传并人工批准封面，所有页面双审后可导出从右到左的固定版式 EPUB，在实际阅读器上检查再发行。

换图会重开本页图文审核，正文签核继续有效。正文改变会重开本页两项审核。角色参考或定义改变会重开引用它的页面的图文审核。更改目标市场会重开全书图文审核。跨页道具和叙事连续性目前由编辑通读确认。

## 可选 AI 插画

在启动服务的终端配置 `OPENAI_API_KEY`。默认模型是 `gpt-image-2`，可用 `ARCHILDBOOK_IMAGE_MODEL` 覆盖。保存分镜后即可生成。正文和分镜用于生成，有角色参考图则一并使用。每次生成一张候选，选图并人工审核后可进入下一分镜。生成不会替换已选插画。正文、分镜和参考图会发送给 OpenAI，调用可能计费。服务不保存密钥。上传插画无需 API 密钥，样稿、编辑、审核与导出可离线使用。

首版采用本地单操作者模式。审核署名用于编辑流程记录。插画候选保存模型与输入参考；正式上架时核对 AI 内容申报要求。单页动态试读可对已选插画播放可逆的镜头推近预览。MP4 导出、生成式视频、自动出稿、多用户协作和商店上架属于后续阶段。
